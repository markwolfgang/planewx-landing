Framework Shift #2
Write two sets of minimums
Pilot Minimums
  • Your hard limits, any aircraft
  • Ceiling, visibility, crosswind
  • Night, IMC comfort
  • Currency / recency floors
Aircraft Minimums
  • Specific to each airframe
  • FIKI / de-ice capability
  • Max crosswind for type
  • Service ceiling, turb tolerance
Use the more restrictive. Always. Automate it — don't negotiate in the moment.
Framework Shift #3
PAVE — use the dangerous letters
P
Pilot
Currency, fatigue, stress, health
A
Aircraft
Airworthiness, equipment, limitations
V
enVironment
Real briefing data — not vibes
E
Ext. Pressures
Write them down. Name them.
"The V (enVironment) must be fed by real briefing data. The E (External Pressures) must be named — not ignored."
Framework Shift #4
Re-decide on a schedule

D-3

Still have options. Make the early call here — before everyone is locked in.

Morning-of
Confirm only
No new decisions here. Pressure is max. Optionality is gone.
